# Vincent M.C. Lee / 李旻宸

Software Engineer · Full-Stack · Cloud · AI-native development

I'm a Taiwan-based software engineer focused on cloud systems, developer tools, and practical AI-assisted engineering workflows. I work across full-stack product surfaces and AWS infrastructure. Outside work, I build local-first AI and developer tools in Rust, TypeScript, Tauri, SvelteKit, and React.

My current focus:

- Building tools for working alongside coding agents: [c9watch](https://github.com/minchenlee/c9watch) shows what a waiting agent needs and what it did while you were away; [Flockbook](https://github.com/minchenlee/flockbook) lets you read and reply to all your agents in one Mac app.
- Shipping [rmdv](https://github.com/minchenlee/rmdv), a native Markdown reader with calm, Notion-like typography.
- Turning repeatable engineering workflows into Claude Code and Codex skills, and running several agents on one codebase without losing track.

## Selected Work

- [c9watch](https://github.com/minchenlee/c9watch) - Mac app and JSON CLI that watches every Claude Code, Codex, Cursor Agent and Pi session on your machine: which agent needs permission, which is working, which is idle. [c9watch.mclee.dev](https://c9watch.mclee.dev)
  `Rust` `Tauri` `SvelteKit`
- [rmdv](https://github.com/minchenlee/rmdv) - native Rust Markdown viewer for folders of `.md` files, with Mermaid, Graphviz DOT, LaTeX math and mind maps. No Electron, no browser. [rmdv.mclee.dev](https://rmdv.mclee.dev)
  `Rust` `Iced`
- [Flockbook](https://github.com/minchenlee/flockbook) - native Mac app for Herdr: read, follow and reply to your coding agents in one place. Unofficial, not affiliated with Herdr, Inc. [flockbook.mclee.dev](https://flockbook.mclee.dev)
  `Swift` `macOS 26`
- [Dictate](https://github.com/minchenlee/dictate) - tiny macOS menu bar app: hold a key, speak, and the text appears at your cursor.
  `Swift` `macOS`
- [Canto](https://github.com/minchenlee/canto) - local-first desktop AI chat client with a real agent loop, approval gates and on-device history.
  `TypeScript` `React 19` `Tauri 2` `Rust`
- [iced_math](https://github.com/minchenlee/iced_math) - native LaTeX math widget for Iced 0.14.
  `Rust` `Iced`
- [Shopulse](https://github.com/minchenlee/Shopulse) - research prototype that compares chat, graphical and hybrid shopping flows.
  `JavaScript` `LLM CUI` `research`
