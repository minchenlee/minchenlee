# Vincent M.C. Lee / 李旻宸

Software Engineer · When a tool I need doesn't exist, I build it.

Most days I build things with a small crew of coding agents: I write the rules they follow, hand out the work and check what comes back. When something in that loop is missing, or when I want to see how something really behaves, I build the tool for it.

AI agents made writing code cheap. What stays scarce is the judgment to build the right thing and carry it all the way to shipped.

## Now building

- **[loadsketch](https://github.com/minchenlee/loadsketch)** — system design simulator: sketch a system, send traffic, see what breaks first. I built it because system design always felt like something that only works on paper. [loadsketch.mclee.dev](https://loadsketch.mclee.dev)
  `TypeScript` `React`
- **[Flockbook](https://github.com/minchenlee/flockbook)** — native Mac app for Herdr: read, follow and reply to your coding agents (Claude Code, Codex, Cursor, pi) in one place. Unofficial, not affiliated with Herdr, Inc. [flockbook.mclee.dev](https://flockbook.mclee.dev)
  `Swift` `macOS 26`
